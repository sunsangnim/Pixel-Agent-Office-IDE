# Pixel Agent Office IDE

Claude Code, Codex CLI, Antigravity CLI를 픽셀 오피스 안의 팀으로 표현하는 Electron 기반
멀티 에이전트 IDE입니다. 명령을 채팅으로 보내면 작업 규모와 `@` 멘션 여부에 따라 담당
팀장을 선택하고, 실제 CLI 세션의 상태를 책상·회의실·탕비실·출입구에 반영합니다.

## 주요 기능

- Claude, Codex, Antigravity 팀장 3명과 팀별 하위 세션 4명, 총 15개 고정 좌석
- 미지정 작업은 Claude 기본 배정, `@코덱스 ...` 같은 직접 멘션은 해당 팀장에게 단독 배정
- 복합 작업은 Claude=코딩, Codex=애니메이션·상호작용, Antigravity=이미지 자산으로 분담
- 팀장별 최대 4개 하위 세션과 전체 동시 Run 6개 제한
- 등록된 직원(`AgentProfile`)과 실제 PTY 프로세스(`AgentRun`) 분리
- 미출근, 좌석 대기, 작업, 승인 대기, 오류, 회의실, 탕비실 상태와 이동 애니메이션
- Claude/Codex/Antigravity별 출력 인식 어댑터와 세션별 실패 격리
- 터미널 드릴다운, 채팅 지시, CLI 템플릿 설정 및 로그인 터미널
- 독립 PNG 배경·가구·캐릭터 레이어로 구성한 16/32-bit풍 픽셀 오피스
- 유리 탕비실과 회의실, 긴 회의 테이블·둘레 의자·상석 노트북, 파티션으로 나눈 비중첩 15석 레이아웃
- `@` 입력 시 멤버 목록형 자동완성과 입력창 내부 멘션 칩

## 실행

Node.js와 사용할 CLI를 설치하고 각 CLI 로그인을 먼저 완료합니다.

```bash
npm install
npm run dev
```

설정 창에서 각 템플릿의 실행 명령과 작업 폴더를 환경에 맞게 지정할 수 있습니다. 실제 CLI는
작업이 배정될 때 지연 실행되며, 빈 좌석을 표시하기 위해 프로세스를 미리 실행하지 않습니다.

## 작업 라우팅

| 입력 유형 | 배정 |
| --- | --- |
| 담당자 미지정, 가벼운 작업 | Claude 팀장 1명 |
| `@클로드`, `@Claude`, `@코덱스`, `@Codex`, `@안티그래피`, `@Antigravity` | 멘션된 팀장 |
| 병렬·전체·아키텍처·마이그레이션·통합 테스트 등 복합 작업 | 3개 팀 오케스트레이션 |

하위 세션은 미출근 또는 대기 상태에서 시작해 작업이 배정되면 빈 책상에 앉습니다. 작업 완료
후에는 슬롯 정책에 따라 좌석, 탕비실 또는 회의실로 이동합니다. 부모 Run 취소 시 자식 Run도
정리하며 중첩 깊이는 2단계로 제한합니다.

채팅 입력창에서 `@`를 입력하면 에이전트 자동완성 목록이 표시됩니다. 한글·영문 이름과 영문
대소문자를 모두 지원하며, 여러 팀을 함께 멘션하면 해당 팀들을 복합 작업으로 배정합니다.

앱 재시작 시 15개 직원 프로필과 좌석 구성은 코드에서 다시 생성됩니다. 실행 중이던 외부 CLI
프로세스는 복구하지 않으며, Run이 없는 직원은 안전하게 `offDuty` 상태로 표시됩니다.

## 개발 및 검증

```bash
npm run typecheck
npm run test:integration
npm run build
```

통합 테스트는 유료 API나 로그인된 실제 에이전트를 호출하지 않습니다. 로컬 가짜 CLI를 실제
`node-pty`로 실행해 라우팅, 15개 프로필, 어댑터 신호, 정상 완료, 오류 감지와 세션 격리를
검증합니다.

## 프로젝트 구조

- `src/main` — Electron 메인 프로세스, PTY·IPC·CLI 어댑터·Run 관리
- `src/preload` — context-isolated IPC 브리지
- `src/renderer` — React 채팅, 오피스, 프로필, 터미널 UI
- `src/shared` — 프로필·Run·정책·공유 타입
- `scripts` — 비용 없는 PTY 통합 테스트 하네스
- `tasks` — 작업별 SRS·PRD·화면설계, PHASES, 최종 결과 문서

전체 구현 이력은 [PHASES.md](./PHASES.md), 최종 통합 검증 결과는
[tasks/phase-20-integration/README.md](./tasks/phase-20-integration/README.md)에서 확인할 수 있습니다.

## 현재 제한사항

- 실제 Claude/Codex/Antigravity 동작은 설치 버전, 로그인 상태와 각 CLI 출력 형식에 영향을 받습니다.
- 실행 중인 외부 CLI 프로세스와 대화 컨텍스트는 앱 재시작 후 자동 재연결하지 않습니다.
- 이미지 자산이 번들 용량의 큰 비중을 차지하므로 배포 단계에서 무손실 최적화를 권장합니다.
