# Phase 20 통합 검증 — SRS · PRD · 화면설계

## PRD

- 단일 작업과 복합 오케스트레이션의 핵심 경로가 회귀하지 않도록 자동 검증한다.
- 실제 계정·비용 없이 PTY, 어댑터 상태, 오류 격리를 반복 검증할 수 있게 한다.
- 최종 사용법과 현재 제한사항을 루트 README에서 확인할 수 있게 한다.

## SRS

- 가짜 에이전트 CLI는 실제 PTY stdin/stdout 경로를 사용한다.
- 정상 프롬프트는 working → completed, 실패 프롬프트는 error 상태를 만들어야 한다.
- 한 세션의 오류 뒤에도 다른 세션은 완료되어야 한다.
- 기본 라우팅, 직접 호명, 복합 작업 라우팅을 검증한다.
- 내장 프로필은 정확히 12개이며 ID가 중복되지 않아야 한다.
- 타입 검사, 통합 테스트, 프로덕션 빌드가 모두 통과해야 한다.

## 화면설계 검증

- 프로필 없음/Run 없음은 미출근 좌석으로 표현한다.
- working, waiting, completed, error가 책상·말풍선·프로필에 매핑된다.
- 실제 픽셀 화면 캡처가 불가능한 환경에서는 번들 자산과 구조 검증 결과를 명시한다.
