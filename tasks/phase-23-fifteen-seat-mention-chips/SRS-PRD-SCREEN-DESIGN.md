# Phase 23 15석 오피스·멘션 칩 — SRS · PRD · 화면설계

## PRD

- 팀별 하위 세션 상한을 4개로 확장하고 15명의 좌석을 한눈에 구분한다.
- 방 경계와 가구 방향을 실제 사용 동선에 맞춘다.
- 멘션을 일반 문자열이 아닌 선택된 대상 칩으로 명확히 표현한다.

## SRS

- Claude, Codex, Antigravity는 팀장 1명과 하위 세션 4명씩 총 15개 프로필을 가져야 한다.
- `maxChildrenPerLead`는 4이며 전역 동시 실행 제한은 별도 정책으로 유지해야 한다.
- 사무실 업무 영역은 3개 팀 열로 나뉘고 팀 사이에 파티션이 보여야 한다.
- 각 팀 열은 상단 팀장 1석과 하단 하위 세션 4석을 배치해야 한다.
- 탕비실 유리벽과 문은 회의실 전면 경계와 같은 높이까지 내려와야 한다.
- 회의실 노트북 화면은 상석 착석자가 바라보는 방향이어야 한다.
- 우측 가로 화분은 세로형 화분으로 교체하고 좌석 금지 영역을 유지해야 한다.
- 멘션 선택 뒤 입력 커서는 멘션 뒤에 위치해야 한다.
- 선택된 멘션은 입력창 안에서 칩 형태로 보여야 하며 전송 텍스트에는 `@Agent`로 포함되어야 한다.
- `@` 자동완성 선택, 상단 멘션 버튼 선택 모두 같은 칩 동작을 사용해야 한다.

## 화면설계

### 오피스

- 전체 오피스 세로 공간을 확장한다.
- Team Claude | Team Codex | Team Antigravity 세 열을 세로 파티션으로 분리한다.
- 각 열: 팀장 데스크 1개 → 하위 세션 데스크 2×2.
- 우측 벽 중앙: 통로와 평행한 세로형 화분.

### 멘션 입력

- 입력 상단 버튼 및 `@` 자동완성에서 에이전트를 선택한다.
- 선택 결과는 입력 영역 상단의 둥근 칩으로 표시한다.
- 칩에는 에이전트 이름과 제거 버튼을 표시한다.
- 텍스트 입력은 칩 다음 영역에 유지하며 선택 직후 즉시 타이핑할 수 있어야 한다.
