# Phase 46 — Front-facing furniture and composed work interaction

Replace diagonal furniture views with axis-aligned assets, add a professional office floor, and remove baked character-plus-desk work imagery in favor of character/chair/desk composition.

## Acceptance criteria

- All runtime furniture faces the camera or a cardinal top-down axis; no diagonal three-quarter assets remain.
- Working actors use their character sprite at the assigned chair/desk interaction point.
- Desk and chair remain independent editable/collidable furniture assets.
- A professional office carpet tile is selectable and changes the entire office floor.
- Typecheck, integration tests, build, and visual QA pass.
