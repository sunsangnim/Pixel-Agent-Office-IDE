# Phase 21 오피스 UI 정리 — SRS · PRD · 화면설계

## PRD

- 오피스 구역과 좌석의 시각적 충돌을 제거해 공간 구분을 명확하게 한다.
- 작업 폴더 선택과 채팅 입력의 흐름을 한 영역에 모아 지시 동선을 줄인다.
- 사용자 이름과 기본 작업 폴더를 실제 사용 환경에 맞춘다.
- 사용하지 않는 프로필 추가 카드를 제거하고 설정 용어를 명확하게 한다.

## SRS

- 탕비실은 회의실과 같은 계열의 유리 벽과 출입구로 막힌 독립 구역이어야 한다.
- 회의실에는 긴 테이블, 둘레 의자, 상석 노트북이 보여야 한다.
- 12개 데스크는 회의실·탕비실·출입구 및 서로 겹치지 않아야 한다.
- 작업 폴더 선택 줄은 사용자 프로필 위가 아니라 채팅 입력창 바로 위에 배치한다.
- 사용자 표시는 `나` 대신 `김태호`를 사용한다.
- 저장된 폴더가 없을 때 기본 폴더는 `C:\Users\win10`이어야 한다.
- 하단 프로필 행의 에이전트 추가 카드는 제거한다.
- 설정 화면의 `새 템플릿 추가`는 `새 에이전트 추가`로 표시한다.

## 화면설계

### 오피스

- 좌상단: 유리 벽으로 둘러싼 탕비실과 내부 설비.
- 상단 중앙: 긴 회의 테이블, 양옆과 하단 의자, 상석 노트북이 있는 유리 회의실.
- 상단 우측: 기존 출입구 유지.
- 업무 좌석: 폐쇄된 상단 구역 아래부터 3행 × 4열로 배치하고 라벨과 가구가 겹치지 않게 한다.

### 채팅 패널

- 상단: `김태호 / 대표` 프로필.
- 본문: 대화 기록.
- 하단: 작업 폴더 선택 줄 → 받는 사람 → 채팅 입력 순서.
