# Phase 33 파티션 바닥 경계 교정 — SRS · PRD · 화면설계

## 요구사항

- Claude, Codex, Antigravity 오른쪽 파티션 3개는 동일한 구현과 동일한 길이를 사용해야 한다.
- 파티션은 민트 타일 바닥에서 끝나고 베이지색 걸레받이로 내려가면 안 된다.
- 기존 `border-right: height 100%` 방식은 제거한다.
- 각 팀 열의 가상 요소는 하단 12px 안전 간격을 사용한다.

## 인수 조건

- [x] 파티션 3개의 길이·두께·색상이 같다.
- [x] 세 파티션 모두 베이지색 걸레받이 위에서 끝난다.
- [x] 좌석과 대표실 배치는 변경되지 않는다.
- [x] 타입 검사·통합 테스트·빌드·화면 검증을 통과한다.
