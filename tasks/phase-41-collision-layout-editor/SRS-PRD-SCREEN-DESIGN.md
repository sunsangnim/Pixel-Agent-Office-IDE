# SRS / PRD / Screen Design

## Requirements

- 에이전트는 가구 AABB를 통과하지 않고, 대각선 이동 시 막히지 않은 축으로 미끄러진다.
- 에이전트끼리 겹치면 최소 이동 벡터로 서로 밀려난다.
- 화면 내 편집 버튼으로 가구를 선택하고 드래그할 수 있다.
- 가구 위치는 로컬 저장되며 새 위치가 경로 탐색과 충돌에 즉시 반영된다.
- 초기화 버튼으로 기본 배치를 복원할 수 있다.

## Screen

- 게임 화면 우측 상단: `인테리어 편집` 토글.
- 편집 중: 안내 문구, `배치 초기화`, 선택 가구의 노란 외곽선.
- 드래그 종료 즉시 위치 저장 및 동적 충돌 맵 갱신.
