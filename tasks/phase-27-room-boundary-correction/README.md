# Phase 27 완료 결과

사용자 표시선을 기준으로 탕비실 문과 대표실 경계·출입 동선을 다시 교정했다.

## 결과

- 탕비실 전면 유리벽을 유지하고 맨 오른쪽 38px 패널에 진한 문틀, 상·하 힌지, 손잡이, 문턱을 적용했다.
- 대표실을 좁은 전체 높이 열에서 우측 하단 `22% × 50%` 사분면으로 변경했다.
- 팀 좌석 영역을 좌측 76%로 제한해 대표실과의 중첩을 방지했다.
- 대표실의 음수 위치를 제거해 우측·하단 벽이 오피스 내부 패딩 안에서 끝나도록 했다.
- 대표실 유리벽을 왼쪽 세로 방향으로 전환하고 중앙 유리문이 일반 사무실로 연결되게 했다.
- 축소된 방 높이에 맞춰 대표 데스크와 하단 휴게 가구를 재배치했다.

## 검증

- 1280×800 Electron 창에서 탕비실 우측 유리문과 대표실 사분면 배치를 직접 확인했다.
- 대표실 문이 사무실 쪽 왼쪽 벽에 있고 모든 벽이 오피스 외곽 안에 포함됨을 확인했다.
- `npm run typecheck`
- `npm run test:integration`
- `npm run build`
- `git diff --check`
