# Phase 32 Antigravity·대표실 파티션 — SRS · PRD · 화면설계

## 요구사항

- Team Antigravity 영역과 대표실 사이에 기존 팀 구획과 같은 픽셀 세로 파티션을 추가한다.
- 파티션은 팀 업무 영역의 오른쪽 경계에 위치해야 한다.
- 대표실 왼쪽 상단 유리문과 이동 통로를 막지 않아야 한다.
- 기존 좌석·대표실·배경 자산 위치는 변경하지 않는다.
- 팀 그리드는 파티션을 내부에서 클리핑해야 하며 새 파티션은 기존 파티션과 동일한 전체 높이를 가져야 한다.
- 기존 파티션과 새 파티션 모두 베이지색 픽셀 외벽 밖으로 나가지 않아야 한다.

## 인수 조건

- [x] Antigravity 오른쪽에 세로 파티션이 표시된다.
- [x] 기존 Claude/Codex 파티션과 색상·두께·하이라이트·길이가 동일하다.
- [x] 대표실 문과 가구가 가려지지 않는다.
- [x] 모든 파티션이 픽셀 오피스 내부 벽선 안에서 끝난다.
- [x] 타입 검사·통합 테스트·빌드·화면 검증을 통과한다.
