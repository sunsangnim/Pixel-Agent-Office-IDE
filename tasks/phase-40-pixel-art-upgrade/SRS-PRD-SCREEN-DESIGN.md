# Phase 40 SRS·PRD·화면설계

## 목표

Phase 39의 게임 로직을 유지하면서 도형 기반 월드를 일관된 16/32-bit 회사 오피스 픽셀 아트로 교체한다.

## 필수 요구사항

- 960×640 논리 월드와 기존 충돌·A*·Y-sort 좌표를 유지한다.
- 배경에는 바닥·벽·유리 파티션·방 라벨만 포함한다.
- 엘리베이터 문, 책상, 의자, 회의 가구, 탕비실 설비, 대표실 가구는 독립 오브젝트로 유지한다.
- 캐릭터와 문이 배경 이미지에 중복 포함되면 실패다.
- 대표실 배치는 좌하단 화분과 탁자, 우상단 소파와 왼쪽 램프, 우하단 책장을 유지한다.
- 확대/축소 시 nearest-neighbor 렌더링을 유지한다.

## 화면 레이어

1. 건축 배경: 타일 바닥, 벽, 유리 프레임, 방 영역
2. 고정 가구: 탕비실·회의실·책상·대표실 가구
3. 문: 양문형 엘리베이터와 방 출입문 애니메이션
4. 캐릭터·소품: y-sort와 상호작용 타임라인
5. 라벨·상태 말풍선

## 인수조건

- 기존 기능/통합 테스트와 프로덕션 빌드가 통과한다.
- 배경과 동적 오브젝트의 중복이 없다.
- 실제 Electron 창에서 잘림·체크무늬·배경 잔여 픽셀이 없다.
- 구형 에셋을 임시로 겹쳐 보이게 하지 않는다.
