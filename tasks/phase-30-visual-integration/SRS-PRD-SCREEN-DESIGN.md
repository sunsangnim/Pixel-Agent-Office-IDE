# Phase 30 대표실 시각 통합 — SRS · PRD · 화면설계

## 요구사항

- 대표실은 별도 불투명 박스가 아니라 회의실과 같은 투명 유리 공간으로 보여야 한다.
- 대표실 바닥은 기존 오피스 타일이 이어져 보여야 한다.
- 대표실은 배경에 포함된 우측 세로 화분과 겹치지 않는 위치에 있어야 한다.
- 회의실과 탕비실 문은 동일한 공용 유리문 프레임·유리·손잡이 스타일을 사용해야 한다.
- 대표실은 픽셀 내부 벽선을 벗어나지 않아야 한다.

## 화면설계

- 대표실: 우측 화분보다 왼쪽, 팀 영역보다 오른쪽인 충돌 없는 구역.
- 유리방: 밝은 상단 프레임, 청록 금속 프레임, 대각 반사광, 기존 타일 투과.
- 탕비실 문: 회의실 문과 동일한 38px 규격의 공용 클래스.

## 인수 조건

- [ ] 대표실 바닥색이 주변 오피스 타일과 자연스럽게 이어진다.
- [ ] 대표실과 우측 화분이 겹치지 않는다.
- [ ] 대표실 유리 프레임이 회의실과 같은 재질로 보인다.
- [ ] 탕비실과 회의실 문이 공용 스타일을 사용한다.
- [ ] 타입 검사·통합 테스트·빌드·실제 화면 검증을 통과한다.
