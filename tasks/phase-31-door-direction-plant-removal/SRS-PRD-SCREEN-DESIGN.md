# Phase 31 문 방향·화분 제거 교정 — SRS · PRD · 화면설계

## 요구사항

- 회의실에는 배경 원본의 기존 문만 남기고 추가 DOM 문을 제거한다.
- 탕비실에만 회의실 기존 문의 시각 규격을 적용한다.
- 대표실 위치는 사용자 지정 우측 하단 위치로 복구한다.
- 대표실과 겹치는 배경 우측 세로 화분과 우측 하단 화분을 이미지 자산에서 제거한다.
- 다른 방, 가구, 외벽, 바닥 타일은 변경하지 않는다.

## 인수 조건

- [ ] 회의실 문이 중복되지 않는다.
- [ ] 탕비실 우측 문이 회의실 기존 문과 같은 형태다.
- [ ] 대표실이 지정된 우측 하단 위치에 있다.
- [ ] 대표실 주변 우측 화분 두 개가 제거된다.
- [ ] 배경의 나머지 픽셀은 유지된다.
- [ ] 타입 검사·통합 테스트·빌드·실제 화면 검증을 통과한다.
