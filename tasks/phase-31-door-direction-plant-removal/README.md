# Phase 31 완료 결과

문 복제 방향을 바로잡고 대표실을 피해서 옮기는 대신 충돌 원인이던 배경 화분을 제거했다.

## 결과

- 회의실 위에 잘못 추가했던 DOM 유리문을 제거해 배경 원본 문 하나만 남겼다.
- 탕비실 우측 문에만 회의실 계열의 밝은 프레임·반투명 유리·우측 손잡이를 적용했다.
- `imagegen` 정밀 오브젝트 편집으로 우측 세로 화분과 우측 하단 화분만 제거한 `office-background-v3.png`를 생성했다.
- 나머지 방, 가구, 상단 작은 화분, 외벽, 민트 타일은 유지했다.
- 실제 화면 좌표를 기준으로 대표실을 우측 12px·하단 16px에 맞춰 베이지색 내부 벽선 안에 붙이고 외곽 클리핑을 유지했다.
- 탕비실 문은 38×40px 고정 크기와 이중 프레임·하부 그림자를 적용해 일반 유리 패널과 구분했다.

## 이미지 편집

- 방식: 내장 imagegen `precise-object-edit`
- 결과: `src/renderer/src/assets/pixel-office/office-background-v3.png`
- 요청: 우측 충돌 화분 두 개와 그림자·화분통만 제거하고 동일한 민트 타일로 복원

## 검증

- 1280×800 Electron 화면에서 회의실 원본 문, 탕비실 단독 복제 문, 대표실 원위치, 화분 비중첩을 직접 확인했다.
- 타입 검사, 통합 테스트, 프로덕션 빌드, diff 검사를 수행했다.
