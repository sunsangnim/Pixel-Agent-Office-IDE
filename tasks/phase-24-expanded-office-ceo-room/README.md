# Phase 24 완료 결과

오피스를 6:5 비율의 확장 캔버스로 개편하고, 가용 창의 폭과 높이 중 더 작은 제약에 맞춰 전체 오피스가 첫 화면에 보이도록 구현했다. 아래 에이전트 카드는 맞춤 계산에서 제외되어 기존처럼 별도 스크롤된다.

## 반영 결과

- 좌측 76%에 Claude, Codex, Antigravity 15석을 3개 파티션으로 배치했다.
- 우측 하단에 유리벽, 출입문, 데스크, 대표 의자, 수납장, 액자, 소파, 화분이 있는 김태호 대표실을 추가했다.
- 탕비실 전면 유리벽과 문을 약 46px 높이의 짧은 띠로 내려 회의실 전면과 같은 형태로 정리했다.
- 데스크의 중복 래스터 레이어와 상태 픽셀을 제거하고 단일 SVG 가구만 표시한다.
- 작은 오피스 좌석 아래의 겹치는 이름·직급 라벨을 숨기고 상세 정보는 에이전트 카드에서 제공한다.
- 메인 칼럼의 수평 스크롤을 차단하고 `100dvh` 기반으로 오피스를 비율 축소한다.

## 검증

- 1280×800 Electron 창에서 오피스 외곽, 15석, 대표실이 스크롤 없이 한 화면에 표시됨을 직접 확인했다.
- `npm run typecheck`
- `npm run test:integration`
- `npm run build`
- `git diff --check`
