# Phase 38 20인 회사원 캐릭터 세트 — SRS · PRD · 화면설계

## 목표

예시 이미지의 작은 전신 픽셀 캐릭터 밀도와 인물 다양성만 참고해, Pixel Agent Office 전용 회사원 캐릭터 20명을 새롭게 디자인한다. 예시 인물의 외형·복장·배색은 복제하지 않는다.

## 인원 구성

1. 김태호 대표 — 고급 네이비 수트, 대표 전용 실루엣
2~6. Team Claude — 팀장 1명·직원 4명, 웜 브라운 포인트
7~11. Team Codex — 팀장 1명·직원 4명, 청록 포인트
12~16. Team Antigravity — 팀장 1명·직원 4명, 보라 포인트
17~20. 확장 인원 — 기획·디자인·QA·운영 직군

## 디자인 요구사항

- 20명 모두 얼굴, 헤어스타일, 피부색, 안경·수염 여부, 정장·오피스 캐주얼 조합이 구분돼야 한다.
- 회사원 분위기를 유지하고 판타지 의상·교복·전투복·과도한 소품은 사용하지 않는다.
- 대표와 팀장은 직원보다 재킷·넥타이·자세가 정돈돼 보여야 한다.
- 각 인물은 머리부터 신발까지 보이는 정면 전신 기본 포즈로 제작한다.
- 투명 배경, 균일한 셀 크기, 5열×4행 배열을 사용한다.
- 안티앨리어싱 없는 또렷한 16/32-bit 게임풍 픽셀 아트로 제작한다.
- 캐릭터 사이가 닿거나 잘리지 않아야 하며 그림자·텍스트·번호를 넣지 않는다.

## 앱 배정

- 셀 0은 대표 프로필과 대표실 캐릭터에 사용한다.
- 셀 1~15는 `AgentProfile` 순서에 따라 세 팀에 배정한다.
- 셀 16~19는 향후 사용자 추가 에이전트를 위해 예약한다.
- CSS `background-position` 또는 canvas crop으로 각 셀을 독립 렌더링한다.
- 기존 상태 애니메이션은 셀 이미지를 유지한 채 위치·착석·말풍선 레이어로 적용한다.

## 인수 조건

- [ ] 정확히 20명의 서로 다른 회사원 캐릭터가 보인다.
- [ ] 5열×4행 셀 정렬이 균일하고 캐릭터가 잘리지 않는다.
- [ ] 대표 1명과 세 팀의 색상 계열이 구분된다.
- [ ] 예시 이미지 인물을 복제하지 않은 독창적 디자인이다.
- [ ] 투명 배경과 픽셀 렌더링이 유지된다.
- [ ] 앱의 대표·15개 AgentProfile에 안정적으로 매핑된다.
- [ ] 타입 검사·통합 테스트·빌드·화면 검증을 통과한다.
