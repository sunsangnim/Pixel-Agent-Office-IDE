# Phase 15 픽셀 이미지 자산화 — SRS · PRD · 화면설계

## PRD

- 코드 도형 중심의 오피스를 실제 픽셀 게임처럼 보이는 래스터 자산 중심 화면으로 개선한다.
- 동적 좌석과 캐릭터 이동 기능을 유지하기 위해 배경, 가구, 캐릭터를 분리한다.
- 사용자가 제공한 민트 타일 오피스와 정장 캐릭터의 픽셀 밀도를 기준으로 통일한다.

## SRS

- 오피스 배경에는 사람과 고정 업무 책상을 포함하지 않는다.
- 가구와 캐릭터 시트는 투명 PNG여야 한다.
- 렌더링에는 `image-rendering: pixelated`를 사용한다.
- 생성 자산은 프로젝트 내부 `src/renderer/src/assets/pixel-office/`에 저장한다.
- 이미지 로드 실패 시 기존 CSS/SVG 표현이 fallback으로 남아야 한다.
- 캐릭터 이동과 상태 말풍선은 기존 React 레이어를 유지한다.

## 화면설계

- 상단 좌측: 탕비실
- 상단 중앙: 유리 회의실
- 상단 우측: 엘리베이터 로비
- 하단: 민트 타일 오픈 오피스와 3×4 좌석
- 배경 이미지 위에 독립 가구/책상, 캐릭터, 상태 UI 순으로 레이어링

## 인수 조건

- [ ] 빈 오피스 배경 PNG가 프로젝트에 저장되고 적용된다.
- [ ] 가구/책상 또는 캐릭터 투명 자산이 프로젝트에 저장된다.
- [ ] 12석과 동적 캐릭터 이동이 이미지 배경 위에서 유지된다.
- [ ] 이미지 실패 fallback과 픽셀 렌더링 설정이 있다.
- [ ] 타입 검사와 프로덕션 빌드가 통과한다.
