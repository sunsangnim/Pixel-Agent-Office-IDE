# Phase 35 오피스 표시영역 확장 — SRS · PRD · 화면설계

## 요구사항

- 오피스 프레임을 사용자가 표시한 초록색 경계까지 가로로 확장한다.
- 우측 채팅 패널의 폭과 내부 구성은 유지한다.
- 오피스 전체가 현재 창 안에서 한눈에 보여야 한다.
- 오피스의 3:2 비율과 내부 방·책상·파티션 배치는 유지한다.
- 창 모드와 전체화면 전환 및 창 크기 변경에도 오피스와 채팅 레이아웃이 깨지지 않아야 한다.

## 화면설계

- 좌측 작업 영역의 오른쪽 내부 여백을 축소해 남는 공간을 오피스 프레임에 할당한다.
- 좌측 여백은 유지하고 채팅 패널과 오피스 사이에는 최소 안전 간격을 둔다.
- 채팅 패널 폭은 가변 범위로 제한하고, 작은 창에서는 패딩과 오피스 높이 제한을 축소한다.
- 앱 최소 창 크기를 지정해 내부 UI가 물리적으로 겹치는 크기까지 축소되지 않게 한다.
- 카드 목록은 오피스 아래에 유지하며 이번 변경의 크기 기준에서 제외한다.

## 인수 조건

- [ ] 오피스 우측 프레임이 채팅 패널 경계 직전까지 확장된다.
- [ ] 오피스 전체가 세로 스크롤 없이 한 화면에 보인다.
- [ ] 우측 채팅 패널의 폭과 기능이 유지된다.
- [ ] 창 모드·전체화면·최소 창 크기에서 오피스 비율과 양쪽 패널이 깨지지 않는다.
- [ ] 타입 검사·통합 테스트·빌드·화면 검증을 통과한다.
