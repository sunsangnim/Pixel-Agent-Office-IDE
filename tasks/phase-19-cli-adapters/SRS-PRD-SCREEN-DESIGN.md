# Phase 19 CLI 어댑터 — SRS · PRD · 화면설계

## PRD

- Claude, Codex, Antigravity를 동일한 오케스트레이션 인터페이스로 실행한다.
- CLI별 입력 방식과 완료/오류 판정을 분리해 한 CLI의 실패가 다른 세션에 전파되지 않게 한다.
- 자동화가 실패해도 기존 터미널 드릴다운으로 직접 복구할 수 있어야 한다.

## SRS

- 공통 어댑터는 실행 설정, 프롬프트 직렬화, 출력 관찰, 완료/오류 판정을 제공한다.
- 어댑터 판정 상태는 `starting`, `ready`, `working`, `waiting`, `completed`, `error`, `exited`로 정규화한다.
- 알 수 없는 사용자 템플릿은 안전한 generic 어댑터를 사용한다.
- 세션별 판정기와 타이머는 PTY 종료/삭제 시 반드시 정리한다.
- CLI 하나의 파싱 예외가 Electron main 프로세스를 종료시키지 않아야 한다.
- 수동 xterm 입출력은 어댑터와 무관하게 계속 동작해야 한다.

## 화면설계

- 책상과 프로필 카드 상태는 정규화된 어댑터 상태를 사용한다.
- 오류에는 종료 코드 또는 판정 이유를 표시할 수 있어야 한다.
- 터미널 모달은 원본 PTY 버퍼를 그대로 제공한다.

## 인수 조건

- [x] 세 내장 CLI와 generic 어댑터가 공통 계약을 구현한다.
- [x] 프롬프트 입력이 CLI별 어댑터를 통과한다.
- [x] 완료·오류·종료 상태가 IPC로 렌더러에 전달된다.
- [x] 어댑터 실패가 다른 세션과 main 프로세스에 영향을 주지 않는다.
- [x] 타입 검사와 프로덕션 빌드가 통과한다.
