# Phase 16 직원·실행 세션 분리 — SRS · PRD · 화면설계

## PRD

- Claude, Codex, Antigravity 각 팀에 팀장 1명과 하위 세션 담당 3명을 고정 직원으로 제공한다.
- CLI 프로세스가 없어도 직원, 직급, 좌석과 미출근 상태가 보여야 한다.
- CLI 실행은 고정 직원 프로필에 연결되는 일시적인 Run으로 관리한다.

## SRS

- `AgentProfile`은 프로필 ID, 템플릿 ID, 직급, 좌석 번호, 표시 이름을 가진다.
- `AgentRun`은 Run ID, 프로필 ID, PTY ID, 작업 폴더, 부모 Run, 공간 상태를 가진다.
- 내장 세 팀의 12개 프로필은 결정적 ID를 사용해 앱 재시작 후 동일하게 복원한다.
- 동일 프로필에는 동시에 하나의 활성 Run만 연결한다.
- 팀장 Run 제거 시 자식 Run을 함께 정리하되 프로필은 삭제하지 않는다.
- 기존 `AgentInstance` API는 마이그레이션 기간에 호환 별칭으로 유지한다.

## 화면설계

- 오피스 좌석은 Run 목록이 아니라 프로필 명부를 기준으로 항상 12개 표시한다.
- Run이 없으면 미출근, Run이 연결되면 해당 어댑터 상태를 표시한다.
- 팀장과 하위 세션 직급을 프로필에서 직접 표시한다.

## 인수 조건

- [ ] 프로세스 없이 12개 프로필과 좌석이 표시된다.
- [ ] Run 생성 시 빈 프로필 하나에 정확히 연결된다.
- [ ] 프로필과 Run API가 분리된다.
- [ ] 팀장 연쇄 종료와 재시작이 프로필 관계를 보존한다.
- [ ] 타입 검사와 프로덕션 빌드가 통과한다.
