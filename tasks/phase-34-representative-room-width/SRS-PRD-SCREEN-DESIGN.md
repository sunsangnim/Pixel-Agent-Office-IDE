# Phase 34 대표실 폭·유리선 교정 — SRS · PRD · 화면설계

## 요구사항

- 대표실 왼쪽 경계를 Team Antigravity 오른쪽 파티션 위치까지 확장한다.
- 대표실 우측·하단 위치는 유지한다.
- 왼쪽 유리문 옆의 두꺼운 검은 세로 프레임을 제거한다.
- 유리문의 밝은 문틀, 반사광, 손잡이는 유지한다.
- 대표실 가구 배치는 유지한다.

## 인수 조건

- [ ] 대표실이 표시된 파티션 경계까지 넓어진다.
- [ ] 유리문 오른쪽의 두꺼운 검은 세로선이 사라진다.
- [ ] 대표실 외벽과 가구가 오피스 내부에 유지된다.
- [ ] 타입 검사·통합 테스트·빌드·화면 검증을 통과한다.
