# Phase 28 완료 결과

사용자 스케치에 맞춰 대표실 가구와 문을 다시 정렬하고 오피스 외곽 침범을 구조적으로 차단했다.

## 결과

- 탕비실 우측 문을 회의실 문과 같은 밝은 3px 프레임, 반투명 반사 유리, 우측 손잡이 스타일로 변경했다.
- 대표실을 업무층 우측 16px·하단 12px 안쪽에 고정하고 오피스 캔버스에 외곽 클리핑을 적용했다.
- 바깥 방향 그림자를 제거하고 모든 프레임 오프셋을 대표실 내부 값으로 제한했다.
- 대표실 문을 왼쪽 유리벽 상단으로 이동했다.
- 대표 데스크를 방 중앙에 배치했다.
- 하단 왼쪽에 화분과 사이드 테이블, 하단 오른쪽에 소파를 배치했다.
- 벽등을 제거하고 상단에는 표찰과 액자만 유지했다.

## 검증

- 1280×800 Electron 창에서 대표실 우측·하단 여백과 전체 벽 포함 상태를 직접 확인했다.
- 문, 중앙 데스크, 하단 양쪽 인테리어가 사용자 스케치 순서로 배치됨을 확인했다.
- `npm run typecheck`
- `npm run test:integration`
- `npm run build`
- `git diff --check`
