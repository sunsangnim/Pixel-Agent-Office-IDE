# Phase 25 오피스 레이아웃 교정 — SRS · PRD · 화면설계

## PRD

- 참고 이미지와 같은 읽기 쉬운 픽셀 데스크를 제공한다.
- 탕비실 출입구를 별도 전면 구조물이 아닌 기존 유리 경계 한 칸짜리 문으로 표현한다.
- 회의실 상석 사용자가 노트북 화면을 바라보는 방향을 정확히 맞춘다.
- 대표실이 화분·팀 좌석·오피스 외곽과 겹치지 않도록 오피스 평면 자체를 확장한다.

## SRS

- 일반 데스크는 밝은 원목 상판, 정면 모니터, 받침대, 키보드, 우측 마우스, 상판 다리, 중앙 의자를 한 개 SVG로 표시해야 한다.
- 데스크는 생성 이미지나 글자 형태의 보조 픽셀 레이어를 사용하지 않아야 한다.
- 탕비실 전면 전체를 덮는 `pantry-glass-wall`은 제거해야 한다.
- 탕비실 문은 기존 방 우측 하단 유리 경계 한 칸 안에 배치해야 한다.
- 회의실 노트북은 상석 의자 쪽에서 화면을 읽는 방향이어야 한다.
- 오피스 캔버스는 대표실 전용 우측 열을 포함하도록 가로로 확장해야 한다.
- 대표실은 오피스 내부 테두리 안에 완전히 포함되고 기존 세로 화분 및 팀 영역과 겹치지 않아야 한다.
- 확장 후에도 창의 가용 폭·높이에 맞춰 오피스 전체가 스크롤 없이 보여야 한다.

## 화면설계

- 상단 좌측부터 탕비실, 회의실, 출입구를 유지한다.
- 하단은 좌측 3개 팀 구획과 우측 대표실 전용 열로 분리한다.
- 세로 화분은 대표실 열 바깥의 통로 또는 제거 가능한 장식 영역에만 둔다.
- 대표실 바닥과 유리벽은 오피스 외곽 테두리에서 안쪽 여백을 확보한다.
- 데스크는 참고 이미지처럼 상판 아래 중앙에 의자가 정렬된 정면 구도로 표시한다.

## 인수 조건

- [x] 참고 이미지 계열의 픽셀 데스크가 15석과 대표 데스크에 적용된다.
- [x] 탕비실에 한 칸짜리 유리문만 표시된다.
- [x] 노트북 방향이 상석 기준으로 수정된다.
- [x] 대표실과 화분·좌석·외곽선이 겹치지 않는다.
- [x] 오피스 전체가 첫 화면에 들어온다.
- [x] 타입 검사·통합 테스트·빌드·실제 화면 검증을 통과한다.
