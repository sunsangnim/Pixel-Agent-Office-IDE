# Phase 25 완료 결과

사용자 참고 화면을 기준으로 데스크, 탕비실 문, 회의실 노트북, 대표실 배치를 다시 교정했다. 대표실을 팀 바닥 위에 절대 배치하던 구조를 없애고 오피스 캔버스 자체에 전용 열을 추가했다.

## 결과

- 15개 일반 좌석과 대표 데스크에 밝은 원목 상판, 모니터, 받침대, 키보드, 마우스, 다리, 중앙 의자로 구성된 단일 SVG 데스크를 적용했다.
- 탕비실 전체 전면 유리 구조를 제거하고 기존 우측 하단 경계 한 칸에만 38×46px 유리문을 배치했다.
- 회의실 노트북을 90도 회전해 왼쪽 상석 의자에서 화면을 보는 방향으로 맞췄다.
- 오피스 비율을 3:2로 확장하고 하단을 `3개 팀 영역 : 대표실 전용 열` 그리드로 구성했다.
- 대표실을 불투명한 독립 공간으로 만들고 기존 화분, 팀 좌석, 외곽선과의 시각적 중첩을 제거했다.
- 대표 데스크에 중복 의자가 생기지 않도록 별도 의자 요소를 제거했다.

## 검증

- 1280×800 Electron 창에서 오피스 외곽과 모든 방이 첫 화면에 들어오는 것을 직접 확인했다.
- 대표실이 초록 외곽선 내부에 있고 팀 데스크 및 화분과 겹치지 않는 것을 확인했다.
- `npm run typecheck`
- `npm run test:integration`
- `npm run build`
- `git diff --check`
