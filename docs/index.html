픽셀 오피스를 지켜보세요

Claude Code, Codex CLI, Antigravity CLI를 픽셀 오피스 속 세 팀으로 표현하는 Electron 기반 멀티 에이전트 IDE입니다. 채팅으로 지시하면 팀장이 배정되고, 실제 CLI 세션의 상태가 책상·회의실·탕비실에 그대로 반영됩니다.

⬇ Windows용 다운로드 GitHub에서 소스 보기
최신 버전

무엇을 할 수 있나요

🧑‍💼

3개 팀, 15개 고정 좌석

Claude·Codex·Antigravity 팀장과 팀별 하위 세션이 각자의 책상에서 실시간 상태를 보여줍니다.

💬

채팅으로 작업 배정

담당자 미지정 시 자동 배정, @ 멘션으로 특정 팀장에게 직접 지시할 수 있습니다.

🧩

복합 작업 오케스트레이션

대규모 작업은 Claude=코딩·문서, Codex=이미지, Antigravity=테스트·검증으로 자동 분담됩니다.

🏙️

생활형 픽셀 오피스

출근·휴식·회의·탕비실 이동까지 갖춘 16/32비트풍 오피스에서 팀의 일상이 이어집니다.

📝

회의 → SRS 자동 정리

세 팀장에게 동시에 의견을 묻고, 회의가 끝나면 하나의 SRS·PRD로 통합 정리합니다.

🔄

자동 업데이트

새 버전이 나오면 앱이 알아서 감지·다운로드하고, 재시작 시 안내 후 설치합니다.

실행하려면 Claude Code, Codex CLI, Antigravity CLI 중 사용할 CLI와 git, gh(GitHub CLI) 로그인이 먼저 필요합니다. 자세한 내용은 README를 참고하세요.
